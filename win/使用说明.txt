Hermes Windows 安装包（= 你 NAS 上那份改过的版本）
================================================

双击「install.bat」即可安装。装完桌面会有两个快捷方式：
  - Hermes 面板     → 打开 http://127.0.0.1:8650/
  - Hermes 终端     → 命令行对话

安装位置：%LOCALAPPDATA%\HermesWin
  app\hermes-src   你的内核 fork（GitHub: vector9584/hermes-agent-custom）
  app\server       面板后端
  app\ui           面板前端
  app\home\data    配置 / .env / 技能 / 知识库 / venv
  app\var          运行时数据

更新：双击「检查更新.bat」，或运行 update.ps1。
  它从 GitHub 拉最新提交，重装依赖，重启面板。版本号在 version.json。

依赖：脚本会自动找 uv / git / node；找不到就下载（需要联网）。
默认开机自启：计划任务 HermesCustomPanel（登录时启动面板）。

卸载：删掉 %LOCALAPPDATA%\HermesWin 和计划任务 HermesCustomPanel 即可。
