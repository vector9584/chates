# CHATÈS 运行说明

这份文件描述本应用自己的目录结构与常用操作。它是通用的，不含任何具体机器的信息。

## 数据在哪里

Windows 安装版把全部用户数据放在：

```
%APPDATA%\CHATÈS\data\
```

包括配置、记忆、技能、知识库、会话库、日志。卸载重装不会删这个目录；想彻底清空需要手动删除。

升级不会覆盖这里已有的文件——只补新增的，不动你改过的。

## 目录用途

| 路径 | 放什么 |
|---|---|
| `data/config.yaml` | 主配置（模型、渠道、端口、工具集） |
| `data/.env` | 密钥与凭据（不随包分发） |
| `data/SOUL.md` | 人格设定 |
| `data/AGENTS.md` | 本文件 |
| `data/memories/` | 长期记忆 |
| `data/skills/` | 技能 |
| `data/knowledge/` | 知识库笔记 |
| `data/sessions/` | 会话记录与产物 |
| `data/state.db` | 会话数据库 |
| `data/venv/` | Python 运行时（安装时生成） |

## 端口

| 端口 | 用途 |
|---|---|
| 8660 | 面板与 API |
| 8752 | 网关（模型调用入口） |
| 9239 | 进程管理 |

改端口改 `config.yaml` 的 `dashboard.port` / `gateway.port`，改完重启生效。

## 重启

面板「设置」里有重启按钮。命令行方式：

```
chates.exe --restart
```

重启会中断当前会话，正在跑的对话需要重新发起。

## 更新

面板会检查 GitHub 上新版本并提示。也可以手动下载安装包覆盖安装——用户数据保存在 `%APPDATA%`，覆盖安装不影响。

## 出问题时

1. 看 `data/logs/` 下最新日志
2. 面板右上角「反馈」可以直接提交问题，内容会存进 `data/var/issues/issues.jsonl`
3. 如果配了 GitHub Issue 同步，提交时会同时开一条仓库 issue

## 配置约定

- **`config.yaml` 不要手改**：面板改配置会走校验和备份，手改容易写坏结构。改坏了把同目录的 `.bak` 覆盖回来。
- **密钥只放 `.env`**：不要写进 `config.yaml`、不要写进技能文件、不要写进对话。
- **技能与知识库是文本**：`.md` / `.txt` / `.json`，不要往里塞 PDF、图片、压缩包。
